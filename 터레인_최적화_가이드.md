# 🌲 Unity Terrain 최적화 가이드

## 📋 현재 상황
- **Batches**: ~3000 (양호)
- **FPS**: ~30 (목표: 60+)
- **주요 원인**: 터레인 나무/잔디 과다

---

# 🔍 문제 분석: 왜 터레인이 무거운가?

```
┌─────────────────────────────────────────────────────────────┐
│                 터레인 성능 병목 원인                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🌲 나무 (Trees)                                            │
│  ├─ 각 나무마다 개별 Draw Call 발생 가능                    │
│  ├─ 그림자 계산 (Shadow Casters)                            │
│  └─ LOD 전환 비용                                           │
│                                                             │
│  🌿 잔디/디테일 (Details/Grass)                             │
│  ├─ 수만~수십만 개의 풀잎 렌더링                            │
│  ├─ 알파 블렌딩 오버드로우                                  │
│  └─ GPU Instancing 미적용 시 치명적                         │
│                                                             │
│  ⛰️ 터레인 자체                                             │
│  ├─ 높은 해상도 = 많은 삼각형                               │
│  └─ 텍스처 스플래팅 레이어 수                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

# 🔧 Step-by-Step 최적화

## Step 1: 터레인 기본 설정 최적화

### 1.1 터레인 선택 및 설정 열기
```
1. Hierarchy에서 Terrain 오브젝트 선택
2. Inspector에서 Terrain 컴포넌트 확인
3. ⚙️ (기어 아이콘) 클릭 → Terrain Settings
```

### 1.2 Pixel Error 조정 (가장 효과적!)
```
┌─────────────────────────────────────────────────────────────┐
│  Mesh Resolution 섹션                                       │
├─────────────────────────────────────────────────────────────┤
│  Pixel Error: 5 → 10~20 으로 증가                          │
│                                                             │
│  📚 설명:                                                   │
│  - 값이 높을수록 터레인 메시가 단순해짐                      │
│  - 1 = 최고 품질, 최저 성능                                 │
│  - 200 = 최저 품질, 최고 성능                               │
│  - 권장: 10~20 (눈에 거의 안 띄면서 성능 향상)              │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 Base Map Distance
```
┌─────────────────────────────────────────────────────────────┐
│  Base Map Distance: 1000 → 500 으로 감소                   │
│                                                             │
│  📚 설명:                                                   │
│  - 이 거리 이상에서는 저해상도 텍스처 사용                   │
│  - 값이 작을수록 성능 향상 (멀리서 품질 저하)               │
└─────────────────────────────────────────────────────────────┘
```

---

## Step 2: 나무(Tree) 최적화 ⭐ 핵심!

### 2.1 Tree Distance 조정
```
┌─────────────────────────────────────────────────────────────┐
│  Tree & Detail Objects 섹션                                 │
├─────────────────────────────────────────────────────────────┤
│  Tree Distance: 5000 → 1000~2000 으로 감소                 │
│                                                             │
│  📚 설명:                                                   │
│  - 이 거리 밖의 나무는 렌더링하지 않음                       │
│  - 게임 플레이에 영향 없는 선에서 최대한 줄이기              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Billboard Start 조정
```
┌─────────────────────────────────────────────────────────────┐
│  Billboard Start: 50 → 30~40 으로 감소                     │
│                                                             │
│  📚 설명:                                                   │
│  - 이 거리부터 3D 나무 → 2D 빌보드로 전환                   │
│  - 빌보드 = 항상 카메라를 향하는 2D 이미지                  │
│  - 값이 작을수록 빨리 빌보드로 전환 → 성능 향상             │
│                                                             │
│  비유: 멀리 있는 나무는 "사진"으로 대체!                    │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 Tree Shadow 비활성화 (큰 효과!)
```
┌─────────────────────────────────────────────────────────────┐
│  나무 그림자 끄기:                                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  방법 1: Terrain Settings에서                               │
│  - Cast Shadows: Off (또는 Two Sided)                      │
│                                                             │
│  방법 2: Quality Settings에서                               │
│  - Edit → Project Settings → Quality                       │
│  - Shadows → Shadow Distance: 100 → 50 으로 감소           │
│                                                             │
│  📚 효과: Shadow Casters 수 대폭 감소!                      │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 나무 개수 자체를 줄이기
```
┌─────────────────────────────────────────────────────────────┐
│  터레인 편집 모드에서 나무 밀도 조정:                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. Terrain 선택 → Paint Trees 탭 (🌲 아이콘)              │
│  2. 현재 나무 개수 확인                                     │
│                                                             │
│  💡 권장 나무 개수:                                         │
│  - 소규모 맵: 500개 이하                                    │
│  - 중규모 맵: 1000~2000개                                   │
│  - 대규모 맵: 3000개 이하                                   │
│                                                             │
│  Shift + 클릭 드래그 = 나무 삭제                            │
│  Tree Density 슬라이더로 밀도 조절                          │
└─────────────────────────────────────────────────────────────┘
```

---

## Step 3: 잔디/디테일(Grass/Details) 최적화 ⭐⭐ 가장 중요!

### 3.1 Detail Distance 조정
```
┌─────────────────────────────────────────────────────────────┐
│  Tree & Detail Objects 섹션                                 │
├─────────────────────────────────────────────────────────────┤
│  Detail Distance: 250 → 80~100 으로 대폭 감소              │
│                                                             │
│  📚 설명:                                                   │
│  - 잔디가 보이는 최대 거리                                  │
│  - 이게 높으면 수십만 개의 풀이 렌더링됨!                   │
│  - 80~100이면 플레이에 충분                                 │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 Detail Density 조정
```
┌─────────────────────────────────────────────────────────────┐
│  Detail Density: 1.0 → 0.3~0.5 로 감소                     │
│                                                             │
│  📚 설명:                                                   │
│  - 단위 면적당 풀 개수                                      │
│  - 0.5 = 절반만 렌더링 → 거의 2배 성능!                    │
│  - 눈에 크게 안 띄면서 성능 대폭 향상                       │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 Detail Resolution 조정 (새 터레인 생성 시)
```
┌─────────────────────────────────────────────────────────────┐
│  ⚠️ 기존 터레인은 수정 불가, 새로 만들 때 설정:            │
├─────────────────────────────────────────────────────────────┤
│  Detail Resolution: 1024 → 512                             │
│  Detail Resolution Per Patch: 32 → 16                      │
│                                                             │
│  📚 설명:                                                   │
│  - 디테일 맵의 해상도                                       │
│  - 낮출수록 성능 향상, 풀 배치 정밀도 감소                  │
└─────────────────────────────────────────────────────────────┘
```

## Step 4: Wind Zone 최적화

### 4.1 Wind 비활성화 또는 약화
```
1. Hierarchy에서 Wind Zone 찾기 (있다면)
2. 삭제하거나 Main/Turbulence 값을 낮추기

📚 설명:
- Wind가 있으면 모든 나무/풀이 매 프레임 흔들림 계산
- 비활성화하면 정적이지만 성능 크게 향상
```

---

## Step 5: Quality Settings 조정

### 5.1 Quality Settings 열기
```
Edit → Project Settings → Quality
```

### 5.2 그림자 설정 최적화
```
┌─────────────────────────────────────────────────────────────┐
│  Shadows 섹션                                               │
├─────────────────────────────────────────────────────────────┤
│  Shadow Resolution: Very High → Medium                     │
│  Shadow Distance: 150 → 50~80                              │
│  Shadow Cascades: 4 → 2                                    │
│                                                             │
│  📚 효과:                                                   │
│  - 그림자 계산 비용 대폭 감소                               │
│  - 멀리 있는 나무 그림자 제거됨                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.3 기타 설정
```
┌─────────────────────────────────────────────────────────────┐
│  Other 섹션                                                 │
├─────────────────────────────────────────────────────────────┤
│  Soft Particles: Off (성능 우선 시)                        │
│  Soft Vegetation: Off                                      │
│  Billboards Face Camera Position: On                       │
└─────────────────────────────────────────────────────────────┘
```

### 6.1 URP Asset 열기
```

2. 사용 중인 URP Asset 선택 (PC_RPAsset 또는 URP-Balanced 등)
```

### 6.2 렌더링 설정
```
┌─────────────────────────────────────────────────────────────┐
│  Rendering 섹션                                             │
├─────────────────────────────────────────────────────────────┤
│  Terrain Holes: 사용 안 하면 Off                           │
│  SRP Batcher: On ✅                                        │
│  Dynamic Batching: On ✅                                   │
└─────────────────────────────────────────────────────────────┘
```

### 6.3 Shadows 섹션 (URP)
```
┌─────────────────────────────────────────────────────────────┐
│  Shadows                                                    │
├─────────────────────────────────────────────────────────────┤
│  Max Distance: 100 → 50                                    │
│  Cascade Count: 4 → 2                                      │
│  Soft Shadows: Off (성능 우선)                             │
└─────────────────────────────────────────────────────────────┘
```

# 💡 추가 팁

## 나무가 정말 많이 필요하다면?

### SpeedTree LOD 활용
```
SpeedTree 나무를 사용 중이라면:
1. 나무 프리팹 선택
2. LOD Group 컴포넌트 확인
3. LOD 전환 거리를 더 가깝게 조정
```

### GPU Instancing 확인
```
나무 Material에서:
1. Material 선택
2. Enable GPU Instancing ✅ 체크
```

## 잔디 대안

### 텍스처로 대체
```
정말 성능이 부족하다면:
- 3D 잔디 대신 터레인 텍스처로 풀 표현
- Detail은 플레이어 주변에만 최소한으로
```
